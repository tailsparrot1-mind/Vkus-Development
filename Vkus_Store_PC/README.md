# Vkus Store — PC

Локальная витрина лицензий Vkus, адаптированная под окно браузера на ПК.

## Запуск
1. Скачайте `index.html`.
2. Откройте файл двойным щелчком в Firefox, Chrome или другом современном браузере.
3. Интернет не обязателен для работы страницы; при наличии сети подключается шрифт Manrope, иначе используется системный sans-serif.

## Что работает
- Выбор BASE / STANDARD / PREMIUM.
- Динамическое обновление цены и списка возможностей.
- Адаптивная раскладка для узких экранов.
- Информационное окно при нажатии на кнопку выбора лицензии.

## Тарифы
- BASE — 79 900 ₽ — VK.
- STANDARD — 174 000 ₽ — VK, Telegram, Одноклассники.
- PREMIUM — 238 000 ₽ — VK, Telegram, Одноклассники, Google, Avito, Yahoo; фильтрация по поисковым запросам; помощь с первыми 3 заявками.

## Важно
Robokassa пока не подключена. Кнопка выбора лицензии не создаёт заказ, не открывает платёж и не списывает деньги. Это локальная визуальная и интерактивная витрина, не готовая платёжная система.

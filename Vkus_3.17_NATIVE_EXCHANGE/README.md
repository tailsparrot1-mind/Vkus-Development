# Vkus Kali Selenium — community search fix

Изменения:
- поиск сообществ использует реальный маршрут VK: `https://vk.ru/search/communities?q=...`;
- старый `search?c[q]=...&c[section]=communities` удалён из основного маршрута;
- Vkus больше не пытается вручную переключать вкладку «Сообщества» после открытия общего поиска;
- ожидание результатов сообщества увеличено, а при отсутствии выдачи в ошибке показывается фактический адрес, который открыл Firefox;
- исправлена обработка комментариев по прямой ссылке на сообщество: отсутствие машинной даты больше не отбрасывает комментарий, если месяц/год не заданы;
- стартовое видео: `assets/vkus_start.mp4`, окно заставки — 8 секунд.


## Вкладка «Биржа» (UI)

Добавлена отдельная вкладка «Биржа» в боковую навигацию. В интерфейсе есть переключение между заявками, специалистами и собственными публикациями; фильтры по запросу, региону, городу и направлению; выбор источников VK, Telegram, Avito, YouDo, Профи.ру и форумов.

Важно: в этой версии реализован интерфейс. Коннекторы внешних площадок, сбор реальных публикаций, классификация намерений и создание публикаций ещё не подключены. Вкладка явно показывает это состояние и не выдаёт демонстрационные записи за реальные результаты.

## Биржа — нативная отрисовка (3.17)
- Экран «Биржа» больше не использует скриншот референса как фон: панели, карточки, подписи, фильтры и плитки источников отрисовываются нативными элементами Canvas; поле запроса — настоящий Tkinter Entry.
- Фирменный логотип и тигр в левой панели взяты из утверждённого референса; остальная рабочая область отрисовывается нативными элементами Tkinter. Компоновка сохраняет исходную координатную сетку 1672×941.
- Фильтры города, радиуса, периода и категории меняют сохранённые значения и перерисовывают подписи. Плитки источников и чекбоксы типов объявлений переключают визуальное состояние; это пока не запускает сбор данных.
- Метрики и блоки находок показывают состояние ожидания подключения источников — никаких демонстрационных чисел или фальшивых заявок. Источники по умолчанию не отмечены как подключённые.
- Поиск пока проверяет ввод и выбранные площадки, но реальный сбор объявлений не подключён. VK/Telegram/Avito/YouDo/Профи.ру/форумы нельзя считать работающими коннекторами этой версии.
- Для визуальной регрессии GitHub Actions открывает настоящее окно Tkinter под Xvfb, сохраняет PNG и прикладывает его вместе с ZIP исходной сборки к запуску workflow как артефакт `Vkus-3.17-Exchange-build`. Тестирует окно и отрисовку, но не запускает Firefox/Selenium и не проверяет реальный сбор объявлений.

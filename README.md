# Vkus Development

Актуальная сборка приложения находится в `Vkus_3.17_NATIVE_EXCHANGE/` (ветка VKUS). Архив последней проверенной сборки формируется GitHub Actions автоматически после каждого изменения.

- Версия интеграции лицензий: 3.18.
- В приложении есть кнопка «Лицензия», локальная витрина открывается в системном браузере.
- Статус по умолчанию: «Не активирована».
- Серверная проверка лицензии и онлайн-оплата пока не подключены.
- Архив сборки: GitHub → Actions → последний успешный запуск → Artifacts → `Vkus-3.18-License-build`.
